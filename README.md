# 🧠 MindForge

### Play. Think. Adapt. Grow.

MindForge is an **Adaptive Cognitive Strategy Game** built with Python and Flask.

It provides short mental challenges that test different cognitive skills and adapts the difficulty based on player performance.

## 🎯 Features

- 🧩 Logic Challenges
- 🔍 Pattern Recognition
- 🧠 Memory Challenges
- ♟️ Strategy Challenges
- 👀 Attention Challenges
- 📊 Performance Scoring
- ⭐ Points & Level System
- 🔥 Streak Tracking
- 🏅 Achievement Badges
- 🤖 Adaptive Difficulty
- 📈 Mind Profile
- 🌐 Web-Based Interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2
- JSON

## 🧠 How MindForge Works

1. The player starts a cognitive challenge.
2. MindForge selects a skill and difficulty.
3. The player answers a series of questions.
4. Performance is calculated based on correctness and time taken.
5. Points are awarded based on performance and difficulty.
6. The player's skill score is updated.
7. The adaptive engine uses performance to determine future challenges.
8. Streaks, levels, and badges are updated as the player progresses.
